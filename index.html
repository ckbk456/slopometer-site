Slopometer

Your daily slop, quantified.

A tiny Mac app that measures one GitHub account's activity and serves it up in your menu bar and on a desktop widget.

Download for Mac

Free and open source (MIT). Needs macOS 14 Sonoma or later.

Slop, plated five ways

  • Grid

    Darker means sloppier.

  • Columns

    One bar per day.

  • Line + 7-day average

    Spiky days, smoothed out.

  • Daily slop quota

    Set a daily PR goal.

  • Menu bar

    Today's count, always up top.

Get sloppy in four steps

  1. 1

    Open Slopometer-1.0.5.dmg.

  2. 2

    Drag it into Applications.

  3. 3

    Type your GitHub username.

  4. 4

    Add the widget via Edit Widgets.

Today's menu

Username only

Free, no sign-in

Your public contribution calendar, read from your GitHub profile page. It's not an official API, so it can break if GitHub changes it.

With a read-only token

Still free

A fine-grained, read-only token adds PRs, private repos, repository filters and a daily quota. Add one per organization. Kept in Keychain.

No account, no tracking.

Not a slop detector.

“Slop” is the joke. It just counts contributions and PRs. It can't spot AI code, won't judge yours, ranks nobody and never writes to GitHub.
